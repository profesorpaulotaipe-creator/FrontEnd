💡 Este objeto se guardó como JSON. guardar() usa JSON.stringify() internamente.
🔑 ¿Por qué necesitamos JSON?

localStorage solo guarda texto. Para guardar un objeto hay que convertirlo primero: 

// ❌ Esto guarda "[object Object]"
localStorage.setItem("datos", { nombre: "Ana" });

// ✅ Así se hace correctamente
const datos = { nombre: "Ana", email: "ana@mail.com" };
localStorage.setItem("datos", JSON.stringify(datos));

// Para leer y usar:
const obj = JSON.parse(localStorage.getItem("datos"));
console.log(obj.nombre); // "Ana"
