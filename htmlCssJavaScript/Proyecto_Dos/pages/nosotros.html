¿Quiénes somos?

Somos un equipo de estudiantes aprendiendo desarrollo web moderno. Este sitio es nuestro proyecto de práctica con HTML, CSS, Bootstrap y JavaScript.

En esta página aprendemos a contar cuántas veces el usuario visita esta sección usando localStorage.

🔢 Patrón: leer → modificar → guardar
1
Leer el valor actual
const visitas = leer("visitas-nosotros", 0);
2
Sumar 1 y guardar
guardar("visitas-nosotros", visitas + 1);
3
Mostrar en pantalla
document.getElementById("numero-visitas").textContent = visitas + 1;
